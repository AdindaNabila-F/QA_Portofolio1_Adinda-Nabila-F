# QA_Portofolio1_Adinda-Nabila-F
Melakukan manual testing web E-commerce Lambdatest Playground. Test case dibuat untuk kondisi pass/fail. Mencakup positive case, negative case. Setiap test case berisi langkah pengujian, data yang digunakan, hasil yang diharapkan, hasil aktual, dan status. Hasil testing digunakan untuk menemukan bug dan memastikan web berjalan sesuai kebutuhan.
