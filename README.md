# QA_Portofolio1_Adinda-Nabila-F
Melakukan manual testing web E-commerce Lambdatest Playground. Membuat Test Scenario, Test Case, Bug Report, dan Test Summary Report pada website “E-commerce Lambdatest Playground” berdasarkan requirement yang telah ditentukan. Test case dibuat untuk kondisi berhasil, gagal, dan kondisi khusus. Test case mencakup positive case, negative case. Setiap test case berisi langkah pengujian, data yang digunakan, hasil yang diharapkan, hasil aktual, dan status Pass/Fail. Hasil testing digunakan untuk menemukan bug dan memastikan website berjalan sesuai kebutuhan.
Scope yang diuji: Fitur Registrasi, Login, Logout, Lupa Password, Keranjang Belanja, dan Search
